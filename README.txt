  ONE PIECE: ГЕОГРАФИЯ ВЕЛИКОГО МОРЯ
  Игра для подготовки к ВПР по географии 6 класс
=====================================================

Авторы: Владимир Лаптев, Дмитрий Пикулин, Ярослав Костюков
Куратор проекта: Воронцов Николай Витальевич

Тема: манга One Piece — команда пиратов плывёт
по четырём морям и Гранд-Лайн, изучая географию Земли
через вымышленный мир One Piece.


КАК ЗАПУСТИТЬ
-------------
1. Установите Python 3 (галочка Add to PATH)
2. (Желательно) pip install pygame
3. Дважды щёлкните start.bat

Папки music/ и animation/ — для своих звуков и картинок.
