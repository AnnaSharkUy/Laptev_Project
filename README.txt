КАК ЗАПУСТИТЬ
-------------
1. Установите Python 3 (галочка Add to PATH)
2. Дважды щёлкните start.bat
   (он сам проверит Python и при необходимости установит pygame)

Если не запускается — откройте check.bat или в cmd:
  py -3 -m pip install pygame
  py -3 main.py

Папки music/ и animation/ — для своих звуков и картинок.
