=====================================================
  ONE-PUNCH MAN: ГЕОГРАФИЧЕСКИЙ ГЕРОЙ
  Игра для подготовки к ВПР по географии 6 класс
=====================================================

Авторы: Владимир Лаптев, Дима Пикулин, Ярослав Костюков
Класс: 6А | Школа № 311 | 2026

Источник вопросов: РЕШУ ВПР (geo6-vpr.sdamgia.ru) + демоверсии ФИОКО


СТРУКТУРА АРХИВА
----------------
OnePunch_Geography_Game.py   — сама игра
start.bat                    — запуск двойным кликом
README.txt                   — эта инструкция
music/                       — папка для музыки
animation/                   — папка для картинок и анимаций


КАК ЗАПУСТИТЬ
-------------
1. Установите Python 3 с https://www.python.org/downloads/
   (обязательно галочка «Add Python to PATH»)

2. (Рекомендуется) Установите pygame для звука:
   pip install pygame

3. Распакуйте архив и дважды щёлкните start.bat


ПАПКА music/
------------
Кладёте сюда файлы:
  menu.mp3      — музыка меню
  battle.mp3    — музыка во время боя (вопросов)
  victory.mp3   — музыка победы
  punch.wav     — звук удара ONE PUNCH!

Форматы: .mp3, .wav, .ogg
Если файла нет — игра работает без этого звука.


ПАПКА animation/
----------------
Кладёте сюда картинки:
  logo.png          — логотип главного меню
  saitama.png       — Сайтама
  genos.png         — Генос
  punch.gif         — анимация удара (или .png)
  monster_wolf.png  — монстр 1 уровня
  monster_tiger.png — монстр 2 уровня
  monster_demon.png — монстр 3 уровня
  victory.png       — картинка победы

Форматы: .png, .gif, .jpg
Если файла нет — игра использует цвет и текст.


ВАЖНО ПРО МУЗЫКУ ONE-PUNCH MAN
------------------------------
Музыку из официальных игр и аниме нельзя
класть в архив и раздавать без разрешения.
Используйте только файлы, на которые у вас
есть права, или бесплатную музыку.
