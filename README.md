# LuffyGame

**Десктопная игра для подготовки к ВПР по географии 5 класса**

Сюжет: команда пиратов из манги *One Piece* плывёт по четырём морям и Гранд-Лайн, изучая географию Земли через вымышленный мир.

Типовые задания **РЕШУ ВПР** / демоверсии **ФИОКО** (география 5 класс):

## Как запустить (Windows)

1. Установите **Python 3** с [python.org](https://www.python.org/downloads/)  
   **Обязательно** поставьте галочку **Add python.exe to PATH**.
2. Дважды щёлкните **`start.bat`**.

Игра откроется в окне. Управление — мышью.

### Если start.bat «не работает»

1. Запустите **`check.bat`** — он покажет, видит ли система Python и pygame.
2. Откройте **командную строку** (Win+R → `cmd`) и выполните:
   ```
   cd /d путь\к\папке\LuffyGame
   py -3 -m pip install pygame
   py -3 main.py
   ```
   или, если команды `py` нет:
   ```
   python -m pip install pygame
   python main.py
   ```
3. Типичные причины:
   - Python не в PATH → переустановите с галочкой «Add to PATH» и **перезагрузите ПК**.
   - Установлен только «магазинный» Python из Microsoft Store → лучше поставить с python.org.
   - Окно мгновенно закрывается → запускайте через `cmd`, чтобы увидеть текст ошибки.
   - Нет звука — нормально, игра работает и без него.

Дополнительно: `run.bat` — короткий запуск без проверок (если всё уже установлено).
